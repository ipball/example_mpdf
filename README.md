# ติดตั้ง Composer และการรันไฟล์ `index.php` ใน PHP

## 1. การติดตั้ง Composer

- ดาวน์โหลดตัวติดตั้งจากเว็บไซต์อย่างเป็นทางการ
- ทำตามขั้นตอนการติดตั้งที่ระบบแนะนำ
- ตรวจสอบให้แน่ใจว่า Composer ได้รับการติดตั้งและสามารถใช้งานได้

## 2. การใช้งาน `composer.json`
รันคำสั่งใน terminal หรือ cmd (ให้ cd เข้าไปที่โฟล์เดอร์โปรเจคก่อน)
`composer install`

## 3. การรันเว็บและไฟล์ `index.php`
พิมพ์ url ในเว็บบราวเซอร์ http://localhost/invoice_project


---
## สรุป
- ติดตั้ง Composer สำหรับจัดการ dependencies
- ใช้ `composer.json` ในการกำหนดค่าแพคเก็จ php
- เปิดเซิร์ฟเวอร์และรันไฟล์ `index.php`
